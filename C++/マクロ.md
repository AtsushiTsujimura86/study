# マクロ

## マクロとは？
C++には「プリプロセッサ」という仕組みがあって、*コンパイルの前処理*で「文字列の置き換え」をしてくれる。  
マクロはこの**置き換えルール**を定義するもの。  
例えば
```cpp
#define PI 3.14
```
と書いておくと、コンパイル前にPIがすべて3.14に置き換わる
```cpp
double r = 2;
double area = PI * r * r; // → コンパイル時には 3.14159 * r * r になる
```
<br>

## 関数マクロ
ただの値だけでなく、関数っぽい形でも置き換えができる。
```cpp
#define SQUARE(x) ((x) * (x))
```
使い方は、
```cpp
int a = 5;
int b = SQUARE(a + 1);   // → ((a + 1) * (a + 1)) に置き換わる
```
<br>

## 文字列化演算子 [#]
マクロには引数を文字列化する特殊機能がある。#varを引数に渡すと、"var"のように文字列リテラルに変換してくれる。
```cpp
#define SHOW(x) SerialDebug.println(#x)

int num = 42;
SHOW(num); // → SerialDebug.println("num");
```
